# 💳 Core Banking - Simulador de Pago Móvil B2C / P2P

Simulador de transacciones financieras y pasarela de pagos móviles desarrollado para el sector bancario venezolano, optimizado con persistencia de datos local y diseño corporativo de alta gama.

## 🚀 Características Técnicas
* **Interfaz Corporativa Avanzada:** Diseñada con CSS Grid/Flexbox y una paleta de colores institucional inspirada en la banca nacional.
* **Gestión de Estado y Persistencia:** Implementación de la API `LocalStorage` para simular el almacenamiento y actualización de saldos y registros transaccionales en tiempo real sin recargar la página.
* **Validación de Reglas de Negocio:** Verificación de fondos disponibles antes de ejecutar la transacción, validación de longitud de números telefónicos y control de cédulas de identidad (V, E, J, G).
* **Módulos Bancarios Integrados:** Soporte para los principales códigos de compensación bancaria de Venezuela (Mercantil, BNC, BDV, Banesco, Provincial, Bancamiga, entre otros).
* **Comprobantes Digitales (Modal):** Generación automática de números de referencia únicos (simulando transacciones de Core / IBM DB2) y comprobantes emergentes aprobados.

## 🛠️ Tecnologías Utilizadas
* **Frontend:** HTML5 Semántico, CSS3 (Variables, Flexbox, Gradientes modernos), JavaScript ES6+ (Manipulación del DOM, Funciones flecha, Objetos y Event Listeners).
* **Almacenamiento:** Browser LocalStorage API.
* **Control de Versiones:** Git & GitHub.
